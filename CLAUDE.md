## How the user wants to work

- **Learning mode**, not execution mode — understanding matters more than speed.
- **Incremental:** introduce one concept at a time. Do not pre-batch notes or
  scaffolding.

  questions to probe whether the idea has landed before moving on.
- After each concept, pause for the user's questions before continuing.
- **Notes folder:** `notes/`. Write the note for a concept *after* discussing it,
  not before. Each note should reflect the depth we actually went into.
